# Edge AI Projects
 
High-level write-ups of edge AI, embedded and UAV projects from my role as Software Engineer at Tidal Wave Technologies (07/2024 - 11/2025). This work is proprietary: no company code, data or images are included. Descriptions are limited to my role, the technology and the results I can share.
 
## 1. Helmet detection on Raspberry Pi 4
- Problem: real-time helmet detection on an edge device
- My role: annotated 4,882 images, trained an object detection model on a COCO checkpoint with Roboflow 3.0, and tuned inference for deployment on Raspberry Pi 4
- Tech: Roboflow 3.0, Python, Raspberry Pi 4
- Result: 66.9% mAP, 76.5% precision, 64.3% recall
 
## 2. Embedded sensor data pipelines
- Problem: reliable real-time environmental telemetry in field deployments
- My role: built data-acquisition pipelines integrating BME280 (I2C) and MH-Z19B (UART) sensors on Raspberry Pi 4/5
- Tech: Python, Go, Raspberry Pi 4/5, I2C, UART
- Result: real-time telemetry used in field deployments
 
## 3. ArduPilot UAV navigation demonstration
- Event: 8th India Mobile Congress 2024, New Delhi
- My role: led the demonstration of autonomous drone navigation on embedded hardware for an international delegate audience
- Tech: ArduPilot, embedded hardware
 
## 4. 5G Centre of Excellence lab deployment, Ranchi
- Period: Oct 2024 - Jan 2025
- My role: on-site integration of edge-AI systems, device configuration and technical support through the lab's formal inauguration
- Tech: edge AI, MEC/5G systems
